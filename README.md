# Конструктор постановлений (раздел ТОС, постановление № 7471)

Инструменты для работы с муниципальной программой «Развитие гражданского общества»
администрации Краснодара: конструктор постановлений о внесении изменений, парсер
решений городской Думы, трекер истории изменений и диагностика.

## Состав

- **`constructor.py`** — единая точка входа, всё в одном файле:
  - `python3 constructor.py` — GUI (tkinter + tksheet): редакции, мероприятия, сверка с Думой, генерация docx;
  - `python3 constructor.py tracker [scan|serve|open]` — трекер изменений раздела ТОС
    (сканирует папку `Наказы/`, строит `changes.json` + `changes.html`, локальный веб-предпросмотр);
  - `python3 constructor.py duma file.htm [file2.htm ...] [-o tos.json] [--csv tos.csv]` —
    парсер выгрузок КонсультантПлюс (раздел «Развитие форм участия населения…»);
  - `python3 constructor.py diagnose` — диагностика без GUI, отчёт в `diag/`;
  - `python3 constructor.py backup <файл...> | --all` — бэкапы с таймстампом;
  - `python3 constructor.py rename-backups` — переименование старых бэкапов.
- **`duma_parser_tos.py`** — тот же парсер отдельным скриптом (оставлен для совместимости).
- **`diagnose.py`** — диагностика отдельным скриптом (дублирует `constructor.py diagnose`).
- **`backup.py`** — бэкапы отдельным скриптом.
- **`docs/`** — примеры сгенерированных постановлений (правильная и бракованная генерация).

Зависимость от `libs/tracker.py` устранена: трекер встроен в `constructor.py`
(self-reference, `tracker.scan()` работает всегда).

## Установка

```bash
pip install -r requirements.txt
```

- `beautifulsoup4`, `lxml` — нужны для команд `duma` и `tracker` (GUI работает и без них);
- `tksheet` — для GUI.

## Данные (в репозиторий не коммитятся)

- `data.json` — редакции и мероприятия (создаётся автоматически при первом запуске GUI);
- `changes.json` / `changes.html` — история решений Думы (создаёт трекер);
- `district_fixes.json` — ручные привязки «мероприятие → округ»;
- `Наказы/` — выгрузки .htm из КонсультантПлюс;
- `diag/`, `Логи/` — отчёты диагностики и журналы.

## Известный баг генерации docx

В таблицах «изложить в следующей редакции» (приложение № 3) могут появляться строки
с нулевой суммой и дубли (см. `docs/` — файл «(неправильно)»): у округа № 27 —
«День семьи, любви и верности» с 0, у МИО Галушко — дубль «Нового года» (0 и 80).
Нумерация строк присваивается счётчиком, а не берётся из номера пункта мероприятия.
Арифметика итогов при этом сходится, но при следующей сверке с Думой строки покажутся
как «лишние». План исправления: фильтровать нулевые строки в разделах-«изложениях»
и брать нумерацию из названия мероприятия (`п. X.Y`).

## Примечание

`data.json` и выгрузки Думы содержат персональные/служебные данные — публиковать
их в открытом репозитории не следует.
